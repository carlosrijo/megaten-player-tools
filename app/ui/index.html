When something goes wrong
The bundle is one zip: the version, a setup check, the log, your settings and a list of your data files. It never holds your spreadsheets, anything read from the game, or pictures. Your Windows user name is left out, and so are character names (they become Character 1, Character 2…) unless you tick the box.

This app only reads the game's memory. It never writes to the game or changes anything in it.
