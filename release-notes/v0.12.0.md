## What's new in 0.12.0

- New **Demon Planner** (Tools): plan a demon's rebirths, rune ranks and Mitama fusion, then its skills, Demon Force and demon equipment, and see what it all costs (apples, macca, runestones, gems, Soul Points and the items to gather) and the stats the demon ends with. Start from any demon you can get or from one of your COMP demons, or pick the boosts you want first and let it work out the ranks. Save builds to a gallery and import demons.
- New **Key Items** page: all 282 key items, which ones you have, what each does and how to get it, with links to its quests.
- New **Dungeon Guides** page: the dungeons where something you do in the run changes the boss, the route or the reward, with numbered steps for each outcome.
- **Character Planner** (was Build Planner): a gear grid in the game's equipment order and a piece editor with tarot and soul rows, slots, LIMIT and weapon mods, following the server's soul infusion rules and saying where to get each part.
- **History**: tick any stats to plot them on the graph (amounts on the left, percentages on the right), and delete snapshots.
- **Overview**: the key stats add Experience (EXP, Partner EXP, Expertise, Soul and Digitalize points, Bethel), Incantation, action boosts and HP / MP cost. The affinity card gets a table with each element's boost, cap and resistance.
- **Quest Database**: every quest checked against the game's event files, so 658 of 680 quests now have steps (was 468).
- **Skill Database**: who sells each demon skill, where and for what. Double and triple stat skills show each stat's rate.
- **Dungeon Database** (was Dungeon Explorer): a drop's tooltip is its full Item Database entry, and scripted rewards are listed.
- **English for the Japanese**: item, skill, demon, status and key item names, descriptions and quest dialogue that the game has only in Japanese now have an English translation, shown greyed out with the Japanese in the tooltip.
- The left bar groups the **Databases** and **Planners**; Demon Rank is now **Demon Ranking**. The Digitalize Planner can search demons by name.
- Effects that need a switch skill count while that switch is on, and say which switch they need (for example Cataclysmic Mind's Spell damage needs Radiant Hands).
- Fixed: the Character Planner refused to start on some PCs when it couldn't read the worn items' own records; it now starts from the items and says what's missing.
