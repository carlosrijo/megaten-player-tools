## What's new in 0.10.0

- **Updates**: BABEL now looks for a new version when it starts and every hour while it is open. When one is out, a notice says so: **Update and restart** downloads it, checks it, and opens BABEL again with the new version. Nothing is installed until you click, and your data folder stays as it is.
- **Settings > Updates**: what's new in the version on offer, **Check now**, and two switches: look for a new version when BABEL starts (on), and include test versions (off).
- Every download is checked before it is installed: it has to be signed by BABEL's own release build, so a changed or broken file is refused.
- This is the version you download by hand one last time: from here on, new versions come to you inside BABEL.
