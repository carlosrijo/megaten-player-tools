## What's new in 0.7.0

- New **Digitalize Planner**: set your goals and get the cheapest plan, with a race map.
- **Back and forward** buttons between pages.
- **Bonuses**: a summoned demon's Demon Force, Mitama set and epitaph rows have pictures, name the item, and list in the tooltip what it gives.
- Skills whose server data is the old version now show what the game says.
- Soul fusion crystals, such as Ogami's, read the crystal's own text when their tokusei have no data.
